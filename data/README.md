# Supplementary data

Supplementary Data 1 contains the primary C1-C4 classification for each image.
Supplementary Data 2 contains English translations of the recorded visual evidence and classification distinctions. These translations are reading aids; the original Chinese observations were not reclassified. Translation model: deepseek-v4.1-flash.
Supplementary Data 3 contains landscape-element segmentation counts, area fractions and inference metadata.

Each CSV contains 5,915 image records. The image_id field links the three tables. The image_name field preserves the original image filename. Rows retain their original order. Pixel counts, fractions, classification codes, hashes, timestamps and model fields have not been recalculated or changed by translation.

C1: Terrain-responsive siting.
C2: Concealment and revelation.
C3: Scenic accentuation.
C4: Access to secluded settings.

Local source paths and output-image paths have been removed. No image files or source directories have been renamed.

Chinese catalogue prefixes in album_id have been romanized for an English-only submission. The following map gives the exact original prefixes using Unicode escape notation. Decode the escaped prefix and append the unchanged numerical suffix to recover the original catalogue identifier:
