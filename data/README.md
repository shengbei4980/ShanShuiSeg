# Supplementary data

Supplementary Data 1 contains the primary C1-C4 classification for each image.
Supplementary Data 2 contains English translations of the recorded visual evidence and classification distinctions. These translations are reading aids; the original Chinese observations were not reclassified. Translation model: deepseek-v4.1-flash.
Supplementary Data 3 contains landscape-element segmentation counts, area fractions and inference metadata.

Each CSV contains 5,915 image records. The image_id field links the three tables. The image_name field preserves the original image filename. Rows retain their original order. Pixel counts, fractions, classification codes, hashes, timestamps and model fields have not been recalculated or changed by translation.

## Validation scope and the legacy split field

The validation set used during ShanShuiSeg-B5 training is the semantic segmentation validation set. It supports pixel-level segmentation evaluation and model selection; it is not an LLM C1-C4 coding validation set. Segmentation validation results should not be interpreted as validation of the LLM-generated labels or their written explanations.

These three supplementary tables contain processed results for 5,915 research images. They are not a manifest of the segmentation training/validation split, and Supplementary Data 3 reports model predictions rather than reference segmentation masks.

Supplementary Data 1 retains a separate, legacy `split` field generated by the original C1-C4 coding workflow:

| Value | Records | Meaning in the original coding workflow |
| --- | ---: | --- |
| `analysis` | 5,058 | Images outside the reserved sampling groups. |
| `pilot` | 20 | Representative images selected for pilot coding. |
| `pilot_companion` | 19 | Other images in groups reserved for pilot coding. |
| `validation` | 400 | Representative images originally reserved for expert coding review. |
| `validation_companion` | 418 | Other images in groups reserved for expert coding review. |

These legacy values do not identify membership in the segmentation validation set. They record sampling assignments; the presence of a `validation` value does not by itself establish that expert review or an independent LLM validation study was completed. Any such evaluation must be described and supported separately. The field values and original classification records are preserved.
